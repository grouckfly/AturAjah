Cara Pemasangan di HP Android:
  1. Klik tombol Download Android di atas.
  2. Setelah unduhan selesai, buka file AturAjah.apk dari notifikasi atau folder Download di File Manager Anda.
  3. Jika muncul konfirmasi keamanan sistem, pilih Setelan lalu aktifkan "Izinkan dari sumber ini".
  4. Ketuk Pasang / Install dan AturAjah siap digunakan secara offline!
Cara Pemasangan di iPhone (iOS):
  1. Unduh aplikasi gratis TestFlight dari App Store di iPhone Anda.
  2. Klik tombol Download iOS (Apple TestFlight) di atas melalui Safari.
  3. Ketuk Terima (Accept) lalu Pasang (Install). Aplikasi langsung muncul di layar utama iPhone Anda tanpa butuh komputer!
  4. Alternatif laptop Windows: Anda juga bisa memasang file AturAjah.ipa ke iPhone menggunakan software gratis Sideloadly.
